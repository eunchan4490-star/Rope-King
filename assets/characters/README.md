# 캐릭터 자산 규칙

캐릭터마다 `assets/characters/<캐릭터 ID>/` 폴더를 만들고 아래 세 파일을 넣습니다.

- `idle.png`: 가만히 있을 때 표시할 투명 배경 전신 이미지
- `jump_sheet.png`: 투명 배경의 가로 4프레임 점프 시트
- `character.json`: 이름, 정렬 순서, 기본 보유 여부

`character.json` 예시:

```json
{
  "display_name": "새 캐릭터",
  "order": 30,
  "unlocked_by_default": true
}
```

점프 시트의 프레임 순서는 다음과 같습니다.

1. 기본 자세
2. 웅크린 자세
3. 상승 자세
4. 공중 자세

각 칸의 크기는 같아야 하며 모든 프레임은 같은 픽셀 배율로 제작합니다. 캐릭터는 각 칸의 아래쪽 중앙을 발 기준으로 맞춥니다. 게임은 각 프레임의 투명 여백을 자동으로 잘라내고 첫 번째 프레임에서 계산한 하나의 공통 배율을 전체 점프 모션에 적용합니다.

게임 시작 시 모든 캐릭터 폴더를 자동으로 검색합니다. 코드에 ID나 이름을 추가할 필요가 없습니다. 보유 캐릭터 선택창은 한 페이지에 3개씩 표시하며 캐릭터가 더 많으면 이전·다음 페이지 버튼이 자동으로 생깁니다. `unlocked_by_default`가 `true`인 캐릭터는 기존 저장 데이터에도 자동 지급됩니다.

현재 기본 캐릭터는 `assets/characters/default/`에 있습니다. 코드에서 `set_player_character("캐릭터 ID")`를 호출해 직접 전환할 수도 있습니다.

캐릭터 ID에는 영문자, 숫자, `_`, `-`만 사용할 수 있습니다. 지정한 캐릭터의 `idle.png`가 없으면 자동으로 `default` 캐릭터를 사용합니다.

## 표준 제작 파이프라인

새 캐릭터는 먼저 가로 5칸짜리 원본 시트 한 장으로 만듭니다. 기본 캐릭터와
같이 원본 단계에서 배경을 완전한 투명(`RGBA alpha=0`)으로 만들어야 합니다.
흰색·회색 배경을 나중에 자동으로 지우는 방식은 사용하지 않습니다.

1. 대기 자세
2. 점프 시작 자세
3. 웅크린 자세
4. 상승 자세
5. 공중 고유 포즈

모든 칸은 같은 폭이어야 하고 캐릭터가 서로 닿지 않아야 합니다. 배경은 반드시
투명이어야 하며, 생성 결과에 배경색이 남아 있으면 먼저 이미지 편집기에서
배경을 제거한 뒤 가져옵니다.

```powershell
./tools/import-character-sheet.ps1 `
  -Source 'C:\path\five-frame-sheet.png' `
  -Id 'new_character' `
  -DisplayName '새 캐릭터' `
  -Order 120 `
  -UnlockedByDefault $true `
  -Validate
```

도구가 자동으로 수행하는 작업:

- 캐릭터 ID 형식 검사
- 투명 알파 채널 유지 여부 검증
- 첫 번째 칸을 `idle.png`로 분리
- 나머지 네 칸을 `jump_sheet.png`로 결합
- `character.json` 생성
- `-Validate` 사용 시 Godot 가져오기, 캐릭터 테스트, `git diff --check` 실행

기존 캐릭터를 교체할 때만 `-Force`를 사용합니다. 생성 순서는 기본 캐릭터 0, 학생 10~29, 일반 캐릭터 30 이상을 기준으로 10씩 띄우면 중간 삽입이 쉽습니다.

## 이미지 생성 프롬프트 규격

기본 캐릭터의 `idle.png`와 `jump_sheet.png`를 스타일 참고 이미지로 사용하고 다음 조건을 고정합니다.

- 줄넘킹의 굵은 픽셀, 큰 사각 눈, 짧은 팔다리, 치비 비율 유지
- 정확히 같은 폭의 5칸 가로 시트
- 모든 칸에서 동일한 얼굴, 의상, 색상, 픽셀 배율 유지
- 1~3번 자세의 발 기준선을 동일하게 정렬
- 캐릭터별로 실루엣이 확실히 다른 공중 포즈 설계
- 글자, 칸 구분선, 바닥, 그림자, 워터마크 금지
- 실제 투명 배경과 캐릭터 사이의 충분한 여백 확보

### 줄넘킹 고정 스타일 규격

- 기준 스타일은 `default`, `schoolgirl_ponytail`, `schoolgirl_bob`와 동일한 치비 도트 스타일입니다.
- 큰 사각 눈, 짧은 팔다리, 한 칸 단위의 굵은 짙은 윤곽선, 제한된 색상 수를 유지합니다.
- 선을 부드럽게 그리거나 고해상도 일러스트처럼 만들지 않습니다. 최종 표시도 nearest 픽셀 필터를 사용합니다.
- 점프 시트는 정확히 4프레임 가로 배열이며, 현재 기준 시트 폭은 2172px(프레임당 543px), 높이는 724px입니다.
- idle은 전신 기준선과 픽셀 밀도를 기준 캐릭터에 맞추며, 생성 후 임의로 늘리거나 찌그러뜨리지 않습니다.
- 새 캐릭터는 반드시 이 규격으로 만든 투명 PNG를 먼저 확정한 뒤 게임에 추가합니다.
