# 캐릭터 제작 표준

새 캐릭터는 `gyaru_girl` 에셋을 기준으로 제작한다. 캐릭터마다 `character.json`, `idle.png`, `jump_sheet.png`를 한 세트로 둔다.

## 이미지 규격

- 픽셀 아트 스타일: 기존 학생·갸루소녀와 같은 도트 밀도, 검은 외곽선, 눈 비율, 색상 대비를 유지한다.
- 배경은 완전 투명으로 제거한다. 흰색·검은색 매트, 반투명 테두리, 발 사이의 잔여 픽셀을 남기지 않는다.
- `jump_sheet.png`: 가로 4칸 스프라이트 시트, 각 칸 543×724px (전체 2172×724px).
- 프레임 순서: 1번 준비, 2번 상승, 3번 하강, 4번 착지/대기.
- `idle.png`: 시트의 4번째 프레임을 그대로 잘라낸 543×724px 이미지.
- 캐릭터 발바닥 기준선을 맞추고, 프레임별 인체 비율과 머리 크기가 급변하지 않게 한다.

## 메타데이터

`character.json` 예시:

```json
{
  "display_name": "캐릭터 이름",
  "order": 50,
  "unlocked_by_default": true
}
```

## 검수 체크리스트

1. 투명 배경으로 확대했을 때 흰색 누끼 테두리와 구멍 잔여물이 없는가?
2. 선택창과 게임 중 정지 상태가 4번째 프레임인가?
3. 점프가 `2 → 1 → 2 → 4` 순서로 보이는가?
4. 기존 캐릭터와 눈·외곽선·도트 크기·인체 비율이 같은가?
5. `idle.png`와 시트의 4번째 칸이 일치하는가?

에셋을 추가한 뒤 Godot 파일 스캔과 `tests/rope_logic_test.gd`를 실행하고, 화면에서 선택창·대기·점프를 직접 확인한다.
