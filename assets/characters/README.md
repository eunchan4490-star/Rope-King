# 캐릭터 제작 표준

새 캐릭터는 `default` 에셋을 기준으로 제작한다. 캐릭터마다 `character.json`, `idle.png`, `jump_sheet.png`를 한 세트로 둔다.

## 점프 모션 (3포즈)

기존 4프레임(준비→상승→하강→착지) 방식은 부자연스러워서 3포즈로 줄였다.

- **1번 (가만히 있는 포즈)**: `idle.png`. 점프 전후 정지 상태.
- **2번 (공중 포즈)**: 팔다리를 크게 뻗은 정점 포즈. 속도가 0에 가까워질 때(정점 부근)만 표시.
- **3번 (중간 전환 포즈)**: 1번과 2번 사이의 자연스러운 중간 동작. 상승/하강 구간 대부분에서 표시.
- 재생 순서: **1 → 3 → 2 → 3 → 1** (정지 → 도약 전환 → 공중 정점 → 착지 전환 → 정지).

## 이미지 규격

- 픽셀 아트 스타일: 기존 캐릭터와 같은 도트 밀도, 검은 외곽선, 눈 비율, 색상 대비를 유지한다.
- 배경은 완전 투명으로 제거한다. 흰색·검은색 매트, 반투명 테두리, 발 사이의 잔여 픽셀을 남기지 않는다.
- `jump_sheet.png`: 가로 2칸 스프라이트 시트, 순서는 **[2번 공중 포즈, 3번 중간 전환 포즈]**. 칸 크기는 idle.png와 동일한 비율을 유지한다.
- `idle.png`: 1번 가만히 있는 포즈를 담은 별도 이미지.
- 캐릭터 발바닥 기준선을 맞추고, 포즈 간 인체 비율과 머리 크기가 급변하지 않게 한다.

## 메타데이터

`character.json` 예시:

```json
{
  "display_name": "캐릭터 이름",
  "order": 50,
  "unlocked_by_default": true
}
```

## 검수 체크리스트

1. 투명 배경으로 확대했을 때 흰색 누끼 테두리와 구멍 잔여물이 없는가?
2. 선택창과 게임 중 정지 상태가 `idle.png`(1번 포즈)인가?
3. 점프가 `1 → 3 → 2 → 3 → 1` 순서로 자연스럽게 보이는가?
4. 기존 캐릭터와 눈·외곽선·도트 크기·인체 비율이 같은가?
5. `jump_sheet.png`의 첫 칸이 2번(공중), 둘째 칸이 3번(중간 전환)인가?

에셋을 추가한 뒤 Godot 파일 스캔과 `tests/rope_logic_test.gd`를 실행하고, 화면에서 선택창·대기·점프를 직접 확인한다.
